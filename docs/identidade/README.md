# Identidade JanuPoints

Opção A escolhida: J creme com ponto dourado sobre fundo marrom.

O original foi gerado com a ferramenta integrada de geração de imagens.
Brief: ícone simples e legível para aplicativo de fidelidade, pontos e
recompensas; J curvo com ponto dourado; paleta marrom #6F3D2E,
creme #FFF5E9 e dourado #D89A31; sem texto.

`janupoints-opcao-a-original.png` preserva o resultado escolhido. Os PNGs
do mobile e do painel derivam dele por redimensionamento. O ícone adaptativo
recebe margem para a máscara do Android. `logo.svg` incorpora o mesmo PNG,
mantendo as URLs das telas de login, recuperação e navegação do painel.

Mobile: `app/frontend-mobile/assets/images/{icon,adaptive-icon,splash-icon,favicon}.png`.
Painel: `app/frontend-web/januprime/public/assets/images/` com logo PNG/SVG,
favicon e ícone de toque Apple.

É necessário recompilar o APK para atualizar o ícone instalado e a splash.
